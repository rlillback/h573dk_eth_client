# HTTPS Client

This is a project to create an HTTPS Capable Client on an STM32H573I-DK development board leveraging the built-in Ethernet port as supported by STMicro.

## Prerequisites
- The STM32H573I-DK development board
- The latest STM32CubeIDE (v1.8.2 was used)

## NOTES
- The STM32CubeIDE software was tested on a Windows computer & on an M3 Mac (M3 Macs require significant configs to work)
- The STM32CubeIDE software has *unknown compatibility* with Linux OSes

## M3 Macs
- Need to give all drive access to USB and Filesystem
- Need to use a powered USB hub as the MacOS will kill the process from a temporary overdraw on power from the USB port
